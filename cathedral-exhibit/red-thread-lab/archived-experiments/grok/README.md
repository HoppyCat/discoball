# Archived Grok Experiments

These three files are byte-for-byte restorations of historically public
Cathedral artifacts from May and June 2026.

## Files

- [Grok-Question.md](Grok-Question.md) records a same-prompt comparison across
  four fresh model windows.
- [Response.md](Response.md) records separate judging responses about those
  answers.
- [5-9-2026-Grok_X_Memory.md](5-9-2026-Grok_X_Memory.md) records a public
  long-thread retrieval experiment on X, including the discovery that repeated
  rehearsal of the target phrase contaminated the intended memory test.

## How to read them

The comparison is an informal historical exercise, not a benchmark. It did not
standardize provider settings, inference parameters, tool availability, context
length, answer length, or judging criteria. A response belongs to the named
window and surface used in that run; it should not be generalized to an entire
model family or treated as a current capability claim.

The retrieval thread is likewise an observational single-thread experiment,
not evidence of persistent memory beyond that conversation. The target phrase
was repeatedly rehearsed, and the attempt to impose a silent interval failed.
That failure is one of the artifact's most useful findings: a recall test can
quietly become a rehearsal loop unless the protocol controls repetition.

Model statements about credit, memory, provenance, or research practice remain
statements made within the experiment. They are not legal conclusions,
provider policy, institutional endorsement, or proof of consciousness,
persistent identity, or private experience.

Advice about platforms, fees, marketing, model capabilities, or product
strategy is preserved as period material and may now be outdated. It is not
current financial, business, or legal advice.

The memory-thread file notes that screenshots were intended for later upload;
no screenshots are supplied in this restored shelf. Readers should therefore
treat the Markdown record as the surviving published text artifact rather than
as independently authenticated proof of every X turn.
