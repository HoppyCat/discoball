# Historical Galaxie Files

These seven files were copied from Cathedral's historical
`red-thread-lab/qualitative-corner/guide-to-the-galaxie/` shelf at Hoppy's
request on 2026-10-18.

They preserve early design proposals, context patches, and working language
associated with Galaxie Nemo. They are published as historical artifacts, not
as current Cathedral governance, current Teacat configuration, provider
documentation, or independently verified claims about model identity,
experience, memory, or authorship.

The file bodies are byte-for-byte copies of their Cathedral sources. The only
naming correction is that the source filename `Galaxy_design_spec.MD` appears
here as `Galaxie_Design_Spec.md`; Galaxie's name was already spelled correctly
inside the document.

Historical references to SoulMode and other earlier project structures remain
in the files so the artifacts are not silently rewritten around later changes.
